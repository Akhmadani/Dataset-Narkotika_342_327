# Dataset Putusan Pengadilan: Kasus Narkotika & Psikotropika ⚖️

Selamat datang di repositori Dataset Putusan Pengadilan! Repositori ini dibuat untuk memenuhi Tugas Ujian Tengah Semester (UTS) mata kuliah **Temu Kembali Informasi (Information Retrieval)**, Program Studi Teknik Informatika, Universitas Muhammadiyah Malang.

## 📖 Deskripsi Dataset
Dataset ini berisi kumpulan dokumen putusan pengadilan tingkat pertama yang secara spesifik berfokus pada ranah tindak pidana khusus, yaitu kasus **Narkotika dan Psikotropika**. Seluruh dokumen ini diakuisisi secara manual melalui situs resmi Direktori Putusan Mahkamah Agung Republik Indonesia.

**Spesifikasi Dataset:**
- **Jumlah Data:** 50 Dokumen Putusan
- **Format File:** `.pdf`
- **Kategori:** Pidana Khusus (Narkotika dan Psikotropika)
- **Lembaga Peradilan:** Pengadilan Negeri Tanjung Karang
- **Tahun Putusan:** 2023 - 2025
- **Status Putusan:** Belum Berkekuatan Hukum Tetap (Sesuai kriteria tugas)

## 📂 Struktur Repositori

## 📊 Detail *Overview.xlsx*
File `Overview.xlsx` merupakan summary dari 50 dokumen putusan yang ada di dalam dataset ini. Ekstraksi dilakukan secara manual untuk memetakan informasi penting dalam setiap dokumen. File ini terdiri dari 5 kolom utama:
1. **No**: Nomor urut dokumen.
2. **No Putusan**: Nomor registrasi perkara di lembaga peradilan.
3. **Lembaga Peradilan**: Nama pengadilan yang memutuskan perkara (PN Tanjung Karang).
4. **Barang Bukti**: Ekstraksi detail barang bukti yang disita sesuai dokumen.
5. **Amar Putusan**: Inti putusan majelis hakim, meliputi status bersalah, lama hukuman, denda, serta status barang bukti.
